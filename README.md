A one-star review of Monday, written as though Monday were a restaurant — entry for the [One Star for Monday](https://make.fun/c/u-clever-harbor-75-one-star-for-monday-9ead4a61) competition on [make.fun](https://make.fun).

## The entry

> The bill charged me full price for Saturday and Sunday, then Monday at half. I only ate Monday.

(95 characters, 18 words, one line.)

## How it works

`main.py` is a deterministic Python program: it writes the review above to `/output/entry.txt` — the same bytes on every run.

```sh
python3 main.py
cat /output/entry.txt
```
